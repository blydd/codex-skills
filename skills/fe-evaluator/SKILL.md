# FE Evaluator（前端面试评估）

## 概览

- **输入**：已填写完成的《<姓名>-面试题与评分表.md》（由 `fe-interviewer` 技能生成，面试官已录入每题候选人回答记录）
- **输出**：`<候选人姓名>/<姓名>-评估报告.md`（文件名以求职者姓名开头，如 `林得富-评估报告.md`）
- **定位**：本技能独立于出题技能 `fe-interviewer`——fe-interviewer 只负责生成评分表，**评估报告统一由本技能生成**。

## 输入处理

- 读取《<姓名>-面试题与评分表.md》中的：候选人关键核验信息、每题「候选人回答记录」区、评分表中的标准参考答案（作为对照基线）。
- 语音转写可能不准确：按上下文推断候选人真实意图与表达，不逐字照搬，并在报告中说明「按上下文推断」。
- **候选人回答记录为空 = 面试官未提问**：**直接过滤**——不评估、不列示、不扣分，评估只基于面试官实际提问且有回答的题目。
- 评估以评分表回答记录与简历事实为准，**不无中生有**（不编造候选人没说过、简历里没有的内容）。
- **面向后端面试官**：报告中的前端术语（如 Proxy 响应式、diff、CORS 预检、强缓存）首次出现时用括号补一句通俗解释，保证非前端面试官也能读懂结论；判断依据要写清「候选人答到了什么 / 没答到什么」，而不是只给一个抽象等级。

## 评估步骤

1. 读取每题「候选人回答记录」（工作簿不打分）；**只保留面试官实际提问且有回答的题目**，无回答的题目视为未提问并过滤，不参与评估。
2. 对照「等级评定标准」给出建议等级（以贯穿各题的真实经历信号 + 整体回答质量为主）。
3. 评估五个维度（见下），并结合固定 JD 匹配度、外包/青岛岗位适配度。
4. 按「等级与评级对应标准」由建议等级映射出**面试评级（A/B/C/D，A 最好、D 最差）**，**保证建议等级与面试评级口径一致**（可因真实性问题在对应档内下调，但不与等级矛盾）。
5. 输出整体评价：强项、短板、综合评语、录用建议（通过/待定/不通过），并说明理由；给出二面重点关注清单（把未问到或回答薄弱的关键项列给项目经理）。
6. 保存为 `<候选人姓名>/<姓名>-评估报告.md`；重名覆盖，保留最新一份。

## 等级评定标准（结合回答质量综合判断）

| 等级 | 典型特征（前端岗） |
|------|---------|
| 初级 | 会用 Vue 写页面、能还原静态设计稿；说不清响应式原理与事件循环；跨域只知道「让后端加个头」；依赖脚手架，没独立处理过线上问题 |
| 中级 | 2-4 年经验；能独立负责模块开发；讲得清 Proxy 响应式、nextTick、key 的作用、跨域方案；能定位并解决首屏慢、打包白屏、样式错乱这类常见问题 |
| 高级 | 4-7 年经验；能主导核心模块或独立负责整个前端项目；讲得清 diff 与 Vue 3 编译期优化、打包分包的取舍、性能量化与治理；能说出多个真实踩坑与权衡；能落地规范（组件封装、ESLint、CR） |
| 资深 | 7 年以上经验；能做技术选型与架构演进（组件库/状态管理/监控/SSR 的取舍）；能把前端工程化、质量保障与交付流程串成体系；对新技术有判断力而非追新 |
| 专家 | 领域专家；能定义前端技术规范与架构标准，主导大型前端项目/跨端方案，解决复杂疑难问题，对行业前沿有深度洞察 |

等级判定以**贯穿各题的真实经历信号**为主、整体回答质量为辅。**真实经历信号**（具体数字、时间、角色、踩坑过程）优先于背题式回答；背题答出但举不出真实案例的，不评为高级以上。

## 面试评级标准（A/B/C/D，A 最好、D 最差）

| 评级 | 总体表现 | 判定要点 | 对应建议等级参考 | 录用建议 |
|---|---|---|---|---|
| **A（优秀）** | 高度匹配岗位，原理与实践俱佳 | 回答质量高、真实经历信号强；五个维度多为强；**Vue 3 相关题答得好**；JD 匹配度高，无明显硬伤 | 高级 / 资深 / 专家 | 推荐（通过），可直接推荐二面/录用 |
| **B（良好）** | 基本胜任，个别短板 | 整体达到岗位要求；回答整体良好但有 1-2 个短板（如工程化或网络偏弱）；JD 匹配度中高 | 中级偏上 ~ 高级 | 推荐二面（通过/待定） |
| **C（一般）** | 未完全达到岗位要求，需谨慎 | 原理薄弱（说不清响应式原理/事件循环/跨域）、真实性存疑或 JD 匹配度中低；存在明显短板 | 中级 ~ 中级偏上 | 待定，谨慎（二面重点验证或按低价录用） |
| **D（较差）** | 明显不匹配，不建议 | 多项关键题答不出或答错（如说不清 Ajax 请求流程、Vue 响应式、跨域完全不会）；或简历与回答明显不符（注水严重） | 中级以下 | 不通过 |

## 等级与评级对应标准（建议等级 ↔ 面试评级，口径必须一致）

| 建议等级 | 面试评级 | 说明 |
|---|---|---|
| 专家 / 资深 | **A** | 原理与实践俱佳、匹配度高，无硬伤 |
| 高级（表现优秀） | **A** | 无明显短板 |
| 高级（有 1-2 个短板） | **B** | 基本胜任 |
| 中级偏上 ~ 高级边缘 | **B 或 C** | 视短板数量与 JD 匹配度 |
| 中级 ~ 中级偏上 | **C** | 未达高级岗位要求 |
| 中级以下 | **D** | 明显不匹配 |

评级规则：
- **先定建议等级，再按上表映射出面试评级**，保证两者一致；评定基线 = 贯穿各题的真实经历信号 + 整体回答质量 + 五个维度 + JD 匹配度；
- **真实性是重要否决项**：简历与回答明显不符、量化指标对不上 → 至少降一级（A→B、B→C、C→D）；
- **Vue 3（第 5 题）权重最高**：该题意外薄弱时（只会用 API、说不清原理与常见坑），即使其他题尚可，也不评为 A；
- **未提问的题目不参与评估，不因未提问而降级**；
- 评级与录用建议映射：A→推荐；B→推荐二面；C→待定（谨慎）；D→不通过。

## 五个评估维度（前端岗位专属）

| 维度 | 评估要点（对照评分表哪些题） |
|---|---|
| **1. 前端基础扎实度** | HTML/CSS 还原与响应式（第 1 题）、原生 JS/ES6/事件循环（第 2 题）、浏览器渲染与网络（第 3 题）、Ajax 与跨域（第 4 题）。看是否讲得清「是什么 + 为什么 + 常见坑」，而非只会调 API |
| **2. Vue 与框架能力（权重最高）** | 第 5 题。Composition API 与 ref/reactive 的坑、Proxy 响应式原理与 Vue 2 对比、diff 与 key、组件通信、Vue Router、Pinia、UI 库、项目配置 |
| **3. 工程化与交付能力** | 第 6 题。构建工具（Vite/Webpack）、依赖与规范（ESLint/Prettier/husky/lock 文件）、打包优化与部署、错误监控与回滚、上线流程 |
| **4. 实战经验与问题解决** | 贯穿各题。项目真实性信号（数字、角色、踩坑过程）、线上问题定位（首屏慢、白屏、跨域、卡顿）、性能优化的量化结果 |
| **5. 协作与综合素质** | 第 6 题及面试记录。沟通表达、编码与注释习惯、多任务与需求变更应对、学习主动性（新标准关注度）、抗压与积极性；第 6 题同时看后台语言与 SQL 的了解程度 |

另需评估：**固定 JD 匹配度**（对照 fe-interviewer 内置的 12 条前端 JD）与**外包/青岛岗位适配度**（核验信息中的所在地、青岛接受度、外包接受度、到岗时间、期望薪资）。

## 评估报告结构（参考 [assets/评估报告模板.md](assets/评估报告模板.md)）

1. **头部信息**：候选人、应聘岗位、面试日期、评估日期、评估说明（只评估实际提问并有回答的题目）
2. **一、面试基本情况与核验补充**：已问/未问题目清单、现场确认的核验信息
3. **二、等级评定**：建议等级 + **面试评级（A/B/C/D）** + 等级与评级对应说明 + 判定依据
4. **三、分题评估**：每题回答质量摘要（答得好/一般/答不出 + 一句评价），术语带通俗解释
5. **四、维度评估**：五个维度 + 固定 JD 匹配度 + 外包/青岛岗位适配度
6. **五、强项 / 短板 / 综合评语**
7. **六、录用建议**：通过 / 待定 / 不通过 + 理由（与面试评级对应：A→推荐、B→推荐二面、C→待定、D→不通过）
8. **七、二面重点关注清单**：回答薄弱的关键技术项与需现场核验项（薪资、学历、量化指标、项目真实性），供项目经理二面验证
