# 海尔JAVA岗位候选人匹配

每次执行本技能，都必须**实时重新读取“岗位招聘管理文档”的最新内容**（不使用缓存、不沿用历史数据），并输出按岗位维度的 Top5 匹配表格。

## 步骤1：筛选海尔岗位需求

查询 `海尔岗位需求` 表，服务端过滤：

1. 岗位状态 == 招聘中
2. 岗位 intersects（包含）“JAVA”

输出每条记录的岗位、岗位要求（全文）、需求团队、级别、需求人数、人天单价。岗位要求用于向用户展示招聘需求与匹配参照。

## 步骤2：筛选简历库候选人

查询 `简历库` 表，服务端过滤：岗位 == `JAVA-开发工程师` 且 面试状态 == `已初试`；分页拉取全量（offset 递增，直到 has_more=false）。

本地过滤（Python 侧）：

1. 面试评级 != `D（未通过）`（空值保留）
2. 简历状态-海尔 ∈ {`已录入`, 空}
3. 二次沟通情况 不含 “不行”

## 步骤3：匹配排序（优先级从高到低）

**核心规则：按“岗位要求”的技术栈与候选人“技术评价”中初面了解到的技术栈/技术水平的匹配度排序；每个岗位取前5人，各岗位人选不重复。**

1. **技术栈匹配度（最重要）**：从岗位要求的文本中提取技术关键词集合（Java、Spring/Spring Boot/Spring Cloud、MySQL、Redis、Kafka/RocketMQ、微服务、高并发、分布式、Python、Oracle、AI/大模型/RAG、财务、物流 等，见脚本内字典）；候选人的技术评价（擅长技术栈、面试问题、技术水平评价）命中其中多少个关键词，命中越多匹配度越高。级别加成：岗位级别为“资深”且候选人评价含“资深”+1；岗位级别为“高级”且候选人评价含“高级/资深”+1。
2. **面试时间距离现在越近越优先**（面试时间缺失者排最后）
3. **面试评级**：A（极好）> B（不错）> C（一般）> 空
4. **期望薪资越低越好**：数值化为下限（“14-15”取14、“上家14 期望12”取12、“16k(可谈）”取16；优先匹配“期望N”写法），缺失排最后

**去重**：按海尔岗位需求表的记录顺序逐个岗位分配：每个岗位从剩余候选人池中按上述排序取前5，已入选其他岗位的人不再参与后续岗位分配，保证各岗位共65个名额互不重复。

**口径说明**：技术栈匹配度基于关键词重叠的确定性启发式计算（脚本内统一字典，大小写不敏感、中文按包含匹配），用于量化“要求的技术栈 vs 初面了解到的技术水平”；如需更精细的人工判断，可在明细表中按“命中技术词”人工复核。

## 步骤4：输出表格

- **主表**：以海尔岗位需求中的岗位为维度（行=岗位），每行列出该岗位匹配度最高的5人（互不重复），格式：`姓名(评级·期望薪资·面试月日)`，按名次1-5排列。
- **匹配依据明细表**：逐岗位逐人输出：岗位/名次/姓名/评级/期望薪资/面试时间/匹配得分/命中技术词（岗位要求∩技术评价）/技术评价要点，供核验匹配依据。

## 执行

```bash
python scripts/match_candidates.py
```

脚本实时查询两个表并输出两张 Markdown 表格。

## 注意

- 数据全部来自真实表，不得编造候选人；查不到即如实说明。
- 技术栈匹配为关键词重叠的确定性启发式，若用户要求人工细化（如按面试问题逐条对照），在输出表格后结合明细表人工复核说明。
- 若用户改口径（如放宽二次沟通限制、包含评级为空的候选人、调整排序优先级、允许跨岗位重复），按用户最新要求调整并同步更新本技能文档。
