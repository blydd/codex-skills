# 岗位候选人信息整理（薄国通待面试口径）

## 数据源（固定，勿改）

- 多维表格：岗位招聘管理文档
- base_token：`ILuybtceKau2X2sbLx0c4SRpnOg`
- 数据表：简历库，table_id：`tblLcOSapd0nUuhl`
- 对应视图：薄国通待面试（vewqSk49Xs）。**不使用视图自带筛选**，一律按下方条件查询全表。

## 筛选条件（分两种口径）

### A. 指定姓名查询时（不加筛选条件，全表按姓名匹配）

- **不设任何服务端过滤条件**——不限面试状态、面试官、岗位、简历状态-海尔。
- 脚本自动分页拉取全表记录，再按姓名（去首尾空白）精确匹配。
- 目的：只要这个人在简历库里，就能按姓名找到，不受状态限制。

### B. 未指定姓名时（宽松口径，列出全部待跟进候选人）

1. 面试状态 == 已初试
2. 面试官 == 薄国通（user id：`ou_a6df4a62c68f7ae95f3d5df0dbcb5640`）
3. 岗位 == JAVA-开发工程师
4. 简历状态-海尔 **不属于** {被占用、已入职、找到工作}（即这三种状态的记录排除掉；简历状态为空的记录保留）

## 输入解析

- **未提供任何姓名**：直接走口径 B，列出全部符合条件的候选人。
- **纯文本姓名**（1 个或多个）：走口径 A，不加筛选条件，全表按姓名精确匹配。
- **图片**：先下载图片到本地，用 Read 工具识别图片中的姓名（一张图可能含多个姓名），把识别出的姓名作为查询目标，走口径 A。
- **多个姓名**：一次全部传入，逐人输出。

## 执行步骤

1. 运行脚本：
   - 未提供姓名：`python scripts/query_candidates.py`（脚本自动按宽松口径分页查询并过滤排除项）。
   - 提供姓名：`python scripts/query_candidates.py <姓名1> [姓名2 ...]`（脚本自动不加筛选条件、分页拉全表、按姓名精确匹配、格式化）。
2. 若脚本不可用（如 lark-cli 未配置），手工执行：
   - **口径 A**（指定姓名）：不传 `--filter-json`，用 `--limit 200 --offset 0` 起逐页拉全表（循环递增 offset 直到 has_more=false），再按姓名（去首尾空白）精确匹配过滤记录。
   - **口径 B**（未指定姓名）：filter.json 只放前 3 个条件（面试状态=已初试 / 面试官=薄国通 / 岗位=JAVA-开发工程师），运行 lark-cli 命令后，在结果里剔除 `简历状态-海尔` 为「被占用」「已入职」「找到工作」的记录，剩余记录全部输出。
3. 逐人按下方固定格式输出。

## 固定输出格式（每人）

```
姓名：{候选人姓名，去首尾空白}
岗位：JAVA-开发工程师
级别：{面试评级}
面试时间1：
面试时间2：
最快到岗日期：{最快到岗时间列值}
期望薪资：{期望薪资列值}
```

字段规则：

- **姓名**：取“候选人姓名”列值，去掉首尾空白（如“武晓凯 ”→“武晓凯”）。
- **岗位**：固定为 `JAVA-开发工程师`（与表中选项一致，不随用户输入大小写变化）。
- **级别**：按“面试评级”列转换——面试评级为 `A（极好）` 时写“资深”，其他（`B（不错）`/`C（一般）`/`D（未通过）`）一律写“高级”。判断 A 只看“A（极好）”这一选项。
- **面试时间1 / 面试时间2**：恒为空，不填任何值。
- **最快到岗日期**：取“最快到岗时间”列值（如“2周内”“随时”“7”），原样输出。
- **期望薪资**：取“期望薪资”列值（如“10K”“14-15”），原样输出。

## 输出纪律

- 多个候选人按查询结果顺序逐人输出，两人之间空一行。
- 查询不到某姓名时，输出“未找到满足条件的候选人：{姓名}”，**不得编造**数据。
- 姓名匹配为精确匹配（去首尾空白后全等）；需要模糊匹配时说明情况。
